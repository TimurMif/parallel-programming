# Параллельное умножение матриц с использованием CUDA

## Описание
Программа на C++/CUDA для перемножения квадратных матриц с распараллеливанием вычислений на графическом процессоре (GPU) с использованием технологии CUDA.

---

## Структура проекта

| Файл               | Назначение                                                            |
|--------------------|-----------------------------------------------------------------------|
| `src/main.cu`      | Основной код CUDA (умножение матриц, замер времени, подсчёт операций) |
| `data/data.txt`    | Файл с таблицей результатов измерений в формате Excel.                |
| `data/results.csv` | Файл с таблицей результатов измерений в текстовом формате.            |


## Оборудование
Эксперименты проводились в среде Google Colab с GPU NVIDIA Tesla T4:

- **CUDA ядер:** 2560
- **Видеопамять:** 16 GB GDDR6
- **Тактовая частота:** 1590 МГц
- **Производительность:** 8.1 TFLOPS

### Выводы
1.  CUDA обеспечивает огромное ускорение по сравнению с однопоточным CPU благодаря тысячам ядер GPU.
2.  Выбор конфигурации блоков влияет на производительность, особенно для больших матриц. Оптимальная конфигурация зависит от размера матрицы и архитектуры GPU.
3.  Для малых матриц накладные расходы на запуск ядра и передачу данных перевешивают выгоду от распараллеливания.
