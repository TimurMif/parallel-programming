# Параллельное умножение матриц с использованием OpenMP

## Описание
Программа на C++ для перемножения квадратных матриц с распараллеливанием потоков вычисления по технологии OpenMP.

---

## Структура проекта

| Файл                  | Назначение                                                           |
|-----------------------|----------------------------------------------------------------------|
| `src/main.cpp`        | Основной код C++ (умножение матриц, замер времени, подсчёт операций) |
| `src/CMakeLists.txt`  | Текстовый файл для настройки процесса сборки под CMake.              |
| `data/statistics.csv` | Файл с таблицей результатов измерений.                               |


### Сборка и запуск проекта
Поместите файлы main.cpp и CMakeLists.txt в одну директорию, затем выполните следующие команды в терминале:

Создание директории для сборки
```bash
mkdir build
cd build
```
Конфигурация проекта (для Visual Studio)
```bash
bash cmake .. -G "Visual Studio 17 2022" -A x64
```
Сборка проекта
```bash
bash cmake --build . --config Release
```
Запуск программы
```bash
bash .\Release\matrix_mult.exe
```

Для проверки, что OpenMP корректно подключен, программа выведет при запуске:
```bash
ИНФОРМАЦИЯ О СИСТЕМЕ:
--------------------
Логических процессоров: 4
Максимальное количество потоков OpenMP: 4
```

### Выводы
1.  **Эффективность параллелизации:** OpenMP показывает отличные результаты при умножении матриц. Для матриц размером от 800x800 эффективность приближается к 100%, что говорит о минимальных накладных расходах на управление потоками.
2.  **Ограничения:** Для малых матриц (200-400) накладные расходы на создание потоков соизмеримы с временем вычислений, поэтому использование параллельных алгоритмов нецелесообразно.
3.  **Масштабируемость:** Алгоритм хорошо масштабируется с ростом размера задачи - чем больше матрица, тем эффективнее используются дополнительные потоки.
