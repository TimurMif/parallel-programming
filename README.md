## Цель работы

### Анализ результатов
- С ростом размера задачи от 200 до 2000 абсолютное время параллельной версии возрастает с 0,001 с до 1,394 с – логарифмическая зависимость.
- Ускорение растёт с размером задачи: для N=200 – 19x, для N=2000 – 45x. Это указывает на хорошую масштабируемость по данным.
