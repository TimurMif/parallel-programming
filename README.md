# Умножение квадратных матриц

## Описание
Программа на C++ для перемножения квадратных матриц с автоматической верификацией результатов с помощью Python (NumPy).

---

## Структура проекта

| Файл                            | Назначение |
|---------------------------------|------------|
| `src/main.cpp`                  | Основной код C++ (умножение матриц, замер времени, подсчёт операций) |
| `scripts/main.py`               | Скрипт для верификации результатов через NumPy |

Также в лабораторной использовались 3 файла input.txt result.txt data.txt
- input.txt - файл, где записаны исходные матрицы, до перемножения
- result.txt - файл, где записаны получившиеся матрицы и замеры каждого эксперимента(время, количество операций)
- data.txt - файл, где записаны только результаты замеров (без результирующих матриц)
---

## Верификация результатов

### Скрипт main.py
Выполняет проверку корректности умножения матриц путём сравнения с эталоном от NumPy.

### Особенности:
- Читает данные из input.txt и result.txt
- Учитывает структуру с разными размерами матриц (200, 400, 800, 1200, 1600, 2000)
- Для каждого размера выполняется по 3 эксперимента

### Результат верификации:

```commandline
============================================================
ВЕРИФИКАЦИЯ УМНОЖЕНИЯ МАТРИЦ
============================================================

--- Верификация: размер 200, эксперимент #1 ---
✓ РЕЗУЛЬТАТЫ СОВПАДАЮТ!

--- Верификация: размер 200, эксперимент #2 ---
✓ РЕЗУЛЬТАТЫ СОВПАДАЮТ!

... (аналогично для всех размеров)

============================================================
ИТОГ ВЕРИФИКАЦИИ:
Размер  200: 3/3 ✓
Размер  400: 3/3 ✓
Размер  800: 3/3 ✓
Размер 1200: 3/3 ✓
Размер 1600: 3/3 ✓

```

Вывод: Программа корректно выполняет умножение матриц для всех размеров. Результаты полностью совпадают с эталонными значениями NumPy.

## Проверка масштабирования (O(n³))
```commandline
ПРОВЕРКА МАСШТАБИРОВАНИЯ:
----------------------------------------
 200 →  400:
  Увеличение времени: 8.32x
  Увеличение размера: 2.00x
  Ожидаемое O(n³): 8.00x
  Соответствие: 104.0%

 400 →  800:
  Увеличение времени: 8.08x
  Увеличение размера: 2.00x
  Ожидаемое O(n³): 8.00x
  Соответствие: 101.0%

 800 → 1200:
  Увеличение времени: 3.44x
  Увеличение размера: 1.50x
  Ожидаемое O(n³): 3.38x
  Соответствие: 101.8%

1200 → 1600:
  Увеличение времени: 2.37x
  Увеличение размера: 1.33x
  Ожидаемое O(n³): 2.37x
  Соответствие: 100.0%

1600 → 2000:
  Увеличение времени: 3.89x
  Увеличение размера: 1.25x
  Ожидаемое O(n³): 1.95x
  Соответствие: 199.5%
```
Вывод: Время выполнения растёт пропорционально O(n³), что соответствует теоретической сложности алгоритма. Отклонения на больших размерах связаны с особенностями работы кэш-памяти.
