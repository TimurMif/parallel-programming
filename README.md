# Параллельное умножение матриц с использованием MPI

## Описание
Программа на C++ для перемножения квадратных матриц с распараллеливанием потоков вычисления по технологии MPI.

---

## Структура проекта

| Файл                  | Назначение                                                           |
|-----------------------|----------------------------------------------------------------------|
| `src/main.cpp`        | Основной код C++ (умножение матриц, замер времени, подсчёт операций) |
| `src/CMakeLists.txt`  | Текстовый файл для настройки процесса сборки под CMake.              |
| `src/mpi.h`           | Заголовочный файл MPI.                                               |
| `src/msmpi.lib`       | Библиотека MS-MPI для линковки.                                      |
| `data/statistics.csv` | Файл с таблицей результатов измерений.                               |


### Сборка и запуск проекта
Поместите файлы из директории `src` в одну директорию, затем выполните следующие команды в терминале:

Создание директории для сборки
```bash
mkdir build
cd build
```
Конфигурация проекта (для Visual Studio)
```bash
cmake .. -G "Visual Studio 17 2022" -A x64
```
Сборка проекта
```bash
cmake --build . --config Release
```
Запуск программы
```bash
mpiexec -n 4 main.exe
```

### Выводы
1.  **Эффективность MPI:** Технология MPI показывает отличные результаты при умножении матриц. Для матриц размером от 800×800 ускорение достигает 3.5-4x
2.  **Сравнение с OpenMP:** MPI демонстрирует лучшую производительность для всех размеров матриц, особенно для средних (800-1200), где преимущество достигает 2.6x. Это объясняется отсутствием накладных расходов на атомарные операции и более эффективным использованием кэш-памяти.
3.  **Масштабируемость:** Алгоритм хорошо масштабируется с ростом размера задачи. Для матрицы 2000×2000 время выполнения сократилось с 115.3 секунд (1 процесс) до 37.6 секунд (4 процесса).
